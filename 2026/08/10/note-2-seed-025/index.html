这篇文章主要介绍构建一个网络爬虫中的各种细节.

首先网络爬虫本身可以视为一个图遍历算法, 例如 BFS 或是 DFS. 所以爬虫的代码实现本身会很类似于这些算法的框架.

在实现网络爬虫的过程中, 有这些细节需要注意:

  1. 对于 url 的去重, 在 href 中可能是相对路径, 需要使用 urllib.urljoin 函数来拼接
  2. 断点重续功能可以使用 sqlite 来追踪, 使用 status 字段 (pending, done, failed) 来保存任务状态, 每次执行时查询数据库中状态为 pending 的字段进行尝试
  3. 需要对 url 进行 normalization, 有一些 url 会带有 fragment, 例如 https://example.com/xxxx/#about 等. 这些都是同一个页面, 应当处理
  4. 对于一些反爬手段, 例如占位页反爬, 需要设置 headers (浏览器 Agent 属性来模拟用户发起的请求) 以及 Session 来保存服务器返回的 Cookie
  5. 可以对页面去重, 利用诸如 SimHash 等手段
