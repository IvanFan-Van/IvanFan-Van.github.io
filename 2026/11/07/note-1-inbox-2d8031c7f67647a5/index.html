2018 卡耐基梅隆深度强化学习和控制公开课

强化学习有信用分配问题，但是在物体检测等领域没有是因为强化学习需要和环境交互，因此最终的 reward 同时依赖于策略以及环境。我们没办法微分环境，来得到每一个神经元对其的影响。

而物体检测领域因为可以直接通过微分得到梯度，因此不会产生信用分配问题

action 的粒度决定了泛化性。 action 的粒度越细，策略的泛化性越差，越难在各个具备不同关节的机器人之间使用。越粗粒度的 action 泛化性越好，但越依赖一个底层控制器将 action 转换为实际的控制指令。

状态空间 = 环境观测 + 机器人状态

只要状态中包含的信息足够多, 那么马尔可夫性质就是成立的事实. 只不过针对我们要保留哪些信息, 可能会造成信息丢失.

马尔可夫性质代表着遗忘, 会不计较模型在执行任务过程中的尝试. 只根据结果打分. 但事实上, 我们应该将 “努力” 也作为一部分状态. 这样 “低努力” + “达成结果” 应该优于 “高努力” + “达成结果”. 因为后者花费了更多的时间或是能量.

能否在重建损失中加入特征的 L1 范数, 来让模型选择性丢弃某些不重要的特征?

agent 之间传递的信息就是 state-value function $V(s)$ 以及 state-action value function $Q(s, a)$.

例如一位年轻的教授, 在和学生大量讨论时会获得很多的即时愉悦. 但是一位经验丰富的教授会说长期来看这并不值得. 因为你浪费了很多本可以提升自己的时间. 老教授向年轻教授传授的就是 State Value Function 以及 State-Action Value Function.

reward 不一定一定来自于环境, 也可以来自于 agent 自身. 例如人类在感到饥饿时会去吃东西. 可能是有一条神经连接着胃和大脑. 当胃感到空空的时候, 会向大脑发送一个 negative signal, 然后促使我去吃东西来抚平这个 negative signal. 而非吃东西给与我 reward.

所以 reward 并不一定是不可控的 (来自于环境的), 可能来自于自身, 是我们可控的.

给定一个策略才有一个 value function. 你无法说一个 value function 是什么样, 在没有阐述策略时.

对于强化学习我们通常有两个任务:

Prediction: 给定 MDP 以及 策略, 求出该策略对应的价值函数 $V_{\pi}$.
Solve: 给定 MDP, 求解最优策略.

$$
\begin{equation}
V_{\pi} = r_{\pi} + \gamma , T_{\pi} V_{\pi} \
V_{\pi} = (I - \gamma , T_{\pi})^{-1} r_{\pi}
\end{equation}
$$
这是矩阵形式 value function 的通解.

deterministic world 中的 value 更新公式

$$
V_{new}(s) = max(V_{old}(s), \quad r(s, a) + V_{old}(s’))
$$
在 indeterministic world, policy, environment, 以及 reward 都是随机的.

$$
V_{\pi} = \sum_{a \in A} \pi(a | s) , \left( r(s, a) + \sum_{s’ \in S} T_{\pi}(s’ | s, a) V_{\pi}(s’) \right)
$$
下一个状态 $s’$ 的价值是所有下一个状态价值的期望:
$$
\mathbb{E}[V_{\pi}(s’)] = \sum_{a \in A} \pi(a | s) , \sum_{s’ \in S} T(s’ | s, a) V_{\pi}(s’)
$$
r 也是一个概率分布, 根据 s, a 采样得到一个 reward.
