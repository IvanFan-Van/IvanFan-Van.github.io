TTS 任务中，wavenet 是个 vocoder，输入音频特征（梅尔频谱），输出 pcm 音频数据

音频本质是一个序列，类似于文字序列，为什么RNN 等模型不能处理？

因为音频序列太过于长了，传统文字序列可能包含上百上千个，但是对于音频，一秒就包含 16000 个 sample。想要分析一秒的音频等同于分析一个包含 16000 单词的序列，这导致了训练困难，推理慢等核心问题。

关于音频的一些基础知识：

音频本身是波，是连续的曲线，但是计算机是离散的，所以在接收音波时，我们对其进行采样，采样率 sample rate 决定了一秒钟执行多少次采样。采样率越高，时间尺度上的点密度越高，波形也就越接近原始波形。根据奈奎斯特定理，当采样数量达到原始音频中最高频率的两倍以上才能达到无损还原。由于人耳只能听到 20hz- 20000hz 的范围，常见的音频采样率为 16000，44100等。采样的内容为音频振幅，由于原始音频振幅范围为（-inf，+inf），为了避免计算机内部存储溢出，会将其归一化到 [-1, 1]。所以对于音频数据来说，就是一长串的振幅值。

除了采样率（sample rate），还有一个量化（quantization）参数，也称为位深（bit depth）或是量化精度，用于将连续的采样值映射到固定的离散值，减少存储需求，常见有 8bit，16bit，32bit 等。分别能存储 [-128, 127] 等

采样后得到的振幅序列数据，就是 pcm数据(pulse code modulation) ，.wav 是一个容器文件，除了包 pcm 数据，还包含一个头文件，里面涵盖了例如采样率，位深等元数据信息。

但是该数据本身还是太过庞大，于是人们通常使用傅里叶变换将其转换到频谱进行处理，为了进一步优化频谱存储，人们提出了梅尔尺度(Mel Scale)，一种基于人耳听觉感知的非线性缩放。根据该尺度缩放后的频谱称为梅尔频谱。梅尔尺度的原理是模糊人类难以分辨的高频数据，保留更多人类敏感的低频数据，来达到听觉无损的频谱数据。傅里叶频谱是一个二维复数数组，表示时频谱。具体不详

TTS 任务和音频生成任务的训练数据是不同的，对于 TTS 数据，训练数据是 (梅尔频谱，PCM)，在推理阶段，先将文本转换为梅尔频谱，在通过梅尔频谱生成音频。而对于音频生成任务，则是类比 llm 自回归，输入 PCM数据，预测下一时刻 PCM 数据。

其核心架构是空洞卷积，提高感受野。30 层网络就可以捕捉 1s 音频内容，而传统 LSTM 类模型则需要上万层。
