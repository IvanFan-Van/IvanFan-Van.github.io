lightweight preprocess network

对于常见的机器人任务，例如抓取物品，或是清理桌面，机器人总是会被各种障碍物和环境干扰。

对于这个我想到了一个假设，就是对于某个任务而言，只有和任务有关的物体是必要的，和任务无关的都是噪声，可以剔除。

基于此我想我能否设计一个轻量级的网络，用于在将图像传输给 VLA 之前，对其进行一些预处理，扔掉属于噪音的部分，以此来提升模型的健壮性和鲁棒性。

为此我设计了一个实验，该实验中使用了一个简单的 2D 环境，其中 agent 使用一个 X 表示，这个环境中有一张桌子，桌子上摆放着若干个物品。而 agent 的目标则是将 X 移动到物品上方，并且执行抓取。

为了验证预处理能够帮助模型在不同的环境中达到一致的效果，我设计了以下几种干扰：

  1. 桌面纹理的变换，对应着物体环境的静态变化。
  2. 桌面上干扰物品的数量
  3. 相机的角度不同，例如倾斜，旋转等

在这个实验中我采用了 BC （Behavior Clone） 方法来训练模型。并且实施了几个 OOD （Out Of Distribution） 来进行测试。

对于预处理，我有三个想法：

  1. 使用一个 mask 将目标物体，agent 以外的所有环境置为 0， 只保留目标物体和 agent 的图像数据
  2. 使用一个 mask 保留目标物体和 agent，但是添加高斯噪声来模糊其余的环境
  3. 使用一个和颜色无关的深度或是灰度图或是固定颜色来表示目标以及 agent（我想验证这种方式能否抗干扰，例如光照等影响）

模型采用 CNN 来进行 VLA。

对于 preprocess network，或许可以考虑 google gemma4 中采用的那样，直接将 image 分为 chunks，加入 position embedding 直接送入一层 MLP 得到 image embedding，移除复杂的 Conv Network

经过一些简单的实验认证，能够得到的结论是，如果将背景忽略掉，得到的结果类似于将一个复杂的任务简单化了。有点像是模拟环境中我们能够为模型提供完美的环境样本一般。

因此这个任务或许可以被重新定义为，构建一个模型，输入真实世界 observation，输出其对应的模拟环境的observation。

因为现在的模型都是在模拟环境中训练的，因此这个 network 的作用就类似于将 OOD 数据转变为 ID 数据。

我们可以通过构建一个和现实世界相同的模拟环境，然后让模拟环境中的相机和现实世界相机的运动保持一致，从而收集到我们希望得到的映射对 （real，sim）。这个可以用于训练模型。

现在的我是直接使用 preprocess 函数来做的，但实际上这个应该由一个神经网络来代替，因此之后的实验应该是训练一个 preprocess network 然后再进行实验。

所以现在的实验结果其实并不能提供证据给这个 idea 的想法成立，因为现在使用了上帝视角，让 OOD 的数据也能被完美分割。但是在事实上，这个 lightweight preprocess network 也会受到 OOD 分布的影响，不知道最后呈现的效果如何。

所以我需要再做一个实验，即单独测试使用 MLP 来做处理，然后看看 其在 OOD 数据集上的效果。
