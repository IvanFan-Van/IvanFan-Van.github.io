模型自进化，只改变 LoRA 参数

现在的模型通常都是离线训练的，不管是预训练还是微调，都是先收集数据，然后微调得到一个固定不动的权重，然后开始推理。在这篇文章中我想思考一个可能的在线学习 （online continuous learning）的架构。

我的想法是允许模型在线调整 LoRA 模块的参数，来达到微调自身的功能。首先模型本身的权重代表了模型思考的能力体现，使用 LoRA 不会影响到模型本身的能力。同时由于 LoRA 本身较小，所以训练应该不会消耗过多的资源。

该 LoRA 理想情况下是对每一个任务单独定制的，因此 LoRA 在在线学习中因为不断的更新而产生灾难性遗忘是被允许的行为。我最终希望的是使用同一套架构，可以让模型在推理时自己自适应下游任务并获得更出色的性能。

对于这个目标的其中一个问题是对于离散输出的任务，例如图像分类任务，该如何限制 llm 只输出我们规定的词语？

借此我想借用 saycan 论文中使用的方法，通过根据给定的标签，我们可以构建一系列的 prompt，拿 MNIST 任务作为例子，我们可以得到以下 prompts：

然后将这些 prompt 输入给llm，让其输出每一个 token 的 logprob，并将移除 prefix 之后的所有 token 的 logprob 加起来作为这个数字的分数。每一次我们选择分数最高的那个数字作为 llm 对这个图像的预测结果。

这个方法也可以应用给其他任何的离散任务。

写到这里，我感觉我的想法有点像 google 的 T5 模型？ 将所有的任务都视为一个语言任务。只不过现在使用多模态模型代替 text input，允许模型理解视频，音频，图片等多模态信息，不过最终仍旧输出文本。

为了验证我的想法，我现在需要了解 LoRA 模块是如何工作的，我需要知道 LoRA 模块是如何训练的，如何被应用到大语言模型上起作用。

我设想设计四个实验来逐步验证想法的可行性，首先从 MNIST/CIFAR 等图像分类任务开始，选择一个 qwen-vl 模型，然后采取上述所说的方式来让 llm 做分类任务，并且加入 LoRA 来检查是否效果会更好。

第二个实验我希望使用 CartPole gymnasium 游戏来做实验，验证 llm-as-agent 的路径。

我期待的是加入了 LoRA 模块的模型，在随着不断的在任务上进行推理，最终会达到比 baseline model 更高的准确率。
