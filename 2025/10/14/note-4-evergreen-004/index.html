为什么 python 中的 sqlite3 除了 conn 对象还会有个 cursor 对象? 该 cursor 对象起到什么作用?

单独设计 conn 以及 cursor 对象的原因有以下几点:

  1. 创建 conn 的开销很大, 对于大部分大型关系型数据库, 例如 postgrl 和 mysql 都采用 client/server 架构, 数据库连接本质是建立了一个 TCP 连接管道, 所以我们不希望每次执行一个 sql 就创建一个新连接等
  2. 为什么一个 conn 会出现多个 cursor? 原因是当执行 SQL 语句时, 结果会被保存在 cursor 对象内以迭代器形式访问, 如果执行新的 SQL 语句就会覆盖上一次执行 SQL 语句得到的结果. 这个时候我们可以通过创建第二个 cursor 来执行不同的 SQL 语句, 而使用第一个 cursor 来进行其他的操作, 例如查看第一个 cursor 执行的 SQL 结果集并用其结果执行其他的 SQL 语句
  3. 在多线程场景下, 例如 web 后端多个用户, 或是多线程处理, 我们希望能让一个 conn 服务于多个用户或线程.
